Скрытые слова

Имена, термины и давно знакомое убираются из списка и из подсветки навсегда. Список отдельный от словаря, так что в тренировку и в экспорт они не попадут.

Только там, где вы разрешили

Расширение запускается на адресах из вашего списка, по умолчанию там один reddit.com. Добавить сайт можно из попапа, одной кнопкой для открытой вкладки.

Текст находится сам, на любом сайте

Статья, документация, тред на Reddit, глава книги: расширению нужен текст, а не конкретный движок. Для трёх сайтов есть готовые правила, на остальных читаемый блок ищется по плотности текста, а доля слов внутри ссылок отсекает меню и подборки «читайте также». Если разбор промахнулся, укажите область мышкой: селектор запомнится для этого домена.

redditwebnovelroyalroadостальные по плотности текста

Правило для своего сайта можно добавить всем сразу: пришлите пул-реквест, заведите issue или напишите в группу в Telegram.

Модель ваша, ключи ваши

Текст страницы уходит только на тот адрес, который вы вписали в настройках. Ключи лежат в настройках браузера, в коде расширения их нет.

Список уровней — внутри

8833 английских слова из CEFR-J и Octanove лежат в самом расширении: 75 КБ, ни одного запроса. Слово, которое список считает ниже вашего уровня, модель в список не протащит, а переводу из словаря он проставит уровень. Ваш собственный словарь тоже хранится только в браузере — сервера у расширения нет.

Облако

Anthropic Messages, Google Gemini и OpenAI-совместимые провайдеры кнопками-пресетами: OpenRouter, Groq, DeepSeek, Mistral, Yandex AI Studio. Кнопка «Проверить подключение» показывает время ответа или ту же ошибку, что увидел бы оверлей.

Словари вместо модели

Одиночное слово переводит Яндекс.Словарь, толкование с примером приходит из dictionaryapi.dev без ключа, фразу можно отдать в DeepL или LibreTranslate. Модель дороже и медленнее, поэтому её очередь последняя.

Похожие инструменты

Ниша живая, выбирать есть из чего. Отличие Erudit одно: это не сервис. Текст уходит только на адрес из ваших настроек, с локальной моделью не уходит вовсе, словарь лежит в браузере, код открыт.

Relingo
Ближе всех по механике: тоже подсвечивает слова по уровню на страницах и в YouTube. Сервис с подпиской, разбор идёт через его облако.
Toucan
Обратный подход: вкрапляет слова изучаемого языка в страницы на родном. После покупки Babbel полностью бесплатен.
Readlang
Перевод по клику и умные карточки, больше ста языков. Сложные слова ищете вы сами, а не расширение.
Language Reactor
Про видео: двойные субтитры и словарь для Netflix и YouTube. Чтение страниц не покрывает.

Установка

В магазинах расширения пока нет, сборка занимает две команды. Нужен Node.js 20 или новее. 

git clone https://github.com/Hakoba/erudit
cd erudit
npm install
npm run build

Chrome

  1. Откройте chrome://extensions
  2. Включите режим разработчика
  3. «Загрузить распакованное расширение», папка dist/chrome

Firefox

  1. Откройте about:debugging
  2. «Этот Firefox», затем «Загрузить временное дополнение»
  3. Выберите dist/firefox/manifest.json

Дальше откройте настройки расширения, укажите адрес модели и нажмите «Проверить подключение». Разрешённые сайты правятся там же или в попапе, одной кнопкой для текущей вкладки.
