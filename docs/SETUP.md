# Erudit — как настроить

Два рабочих варианта: **совсем без денег и ключей** и **с языковой моделью**. Первый
включён сразу после установки, второй — одна страница настроек. Разница в том, кто ищет
слова: офлайн-профиль знает только отдельные английские слова, модель видит фразы,
контекст и умеет объяснять. Подробности про каждую кнопку — в [FAQ](FAQ.md).

## Общие шаги

Они одинаковы для обоих вариантов и занимают пару минут.

### 1. Установить

Расширение собирается из исходников (Node.js 20+):

```bash
git clone https://github.com/Hakoba/erudit
cd erudit
npm install
npm run build
```

**Chrome:** `chrome://extensions` → режим разработчика → «Загрузить распакованное
расширение» → `dist/chrome`.

**Firefox:** `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» →
любой файл внутри `dist/firefox`.

### 2. Уровень и языки

После установки откроется страница первого запуска. Там три вещи:

- **Мой уровень** — порог, а не фильтр. Разбирается всё, что выше: на B1 в список
  попадают B2, C1 и C2. Не знаете — оставьте B1 и поднимите, когда список станет
  слишком длинным.
- **Читаю на / перевод на** — язык страниц и язык, на котором показывать перевод.
  Офлайн-профиль есть только для английского; для другого языка чтения нужна модель
  (вариант 2).
- **Сайты** — расширение работает только там, где разрешено. По умолчанию в списке
  один `reddit.com`. Добавить текущий сайт быстрее всего из попапа расширения:
  кнопка «Разрешить <домен>», потом перезагрузить страницу. В настройках → «Сайты»
  список можно перевернуть: «везде, кроме перечисленных» — почта, банки и госуслуги
  при этом всё равно остаются нетронутыми.

### 3. Проверить

Откройте любую страницу с текстом на разрешённом сайте (на странице первого запуска
есть ссылка на демо). Через пару секунд в тексте загорятся слова выше уровня,
а в панели — их список с переводом. В Chrome панель открывается ярлыком у правого края
страницы или `Ctrl+Shift+E` (`⌘+Shift+E`), в Firefox она уже прижата к странице.

Дальше — один из двух вариантов.

## Вариант 1. Полностью бесплатно

Ничего не платите, ничего не регистрируете, ничего не ставите на компьютер. Так
расширение работает сразу после установки.

### Кто ищет слова

Настройки → «Чтение» → «Кто ищет сложные слова» → **Офлайн-профиль CEFR**. Это значение
по умолчанию. Уровень каждого английского слова берётся из встроенного списка
(8 833 записи), сеть для этого не нужна.

### Кто переводит

Настройки → «Словари» → «Чем переводить». Из коробки стоит MyMemory — единственный
бесключевой переводчик с официальным тарифом; для профиля его хватает.

- **Яндекс.Словарь** — несколько значений, транскрипция, часть речи, но только
  по своему ключу: новых Яндекс больше не выдаёт. Пункт для тех, у кого ключ есть.
- **MyMemory** — единственный машинный переводчик с официальным бесплатным тарифом:
  5 000 слов в день, 50 000 — если указать почту в поле рядом. Берёт и фразы, они
  пригодятся для перевода выделенного текста.
- **Google Translate, Lingva** работают без ключа, но через внутренние точки чужих
  веб-клиентов: могут закрыться или начать банить по частоте в любой день. Google
  банит первым; Lingva зависит от инстанса (`lingva.ml`, `lingva.lunar.icu`).
  DeepL из России отвечает 451.

Толкования в раскрытой карточке слова (транскрипция, значения, примеры) идут
из Яндекс.Словаря и dictionaryapi.dev всегда, независимо от этой настройки.

### Что работает

Подсветка и список слов, перевод при наведении и по выделению, словарь, тренировка
по интервалам, подмена слов на страницах родного языка, экспорт и импорт Anki.
Всё это офлайн или с бесплатными источниками.

### Чего не будет

- **Фраз и идиом.** Профиль знает слова по одному; «take it for granted» он не увидит.
- **Контекста.** Слово с несколькими значениями переводится без учёта предложения.
- **Пояснений модели.** Кнопка «Пояснение модели» в карточке без модели не работает.
- **Других языков чтения.** Профиль собран только по английскому.

Если чего-то из этого не хватает — вариант 2. Всё настроенное остаётся, меняется
только один переключатель.

## Вариант 2. С моделью

Модель находит слова и фразы в контексте, ставит уровень сама, объясняет по кнопке
и работает с любым языком чтения. Ключ и адрес хранятся в настройках браузера
и уходят только провайдеру модели.

### Локальная модель: бесплатно, но нужен компьютер посильнее

Подходит, если есть [LM Studio](https://lmstudio.ai), [Ollama](https://ollama.com)
или другой сервер с OpenAI-совместимым API.

1. Запустите сервер и загрузите модель. Для разбора хватает модели на 7–12 миллиардов
   параметров; на процессоре без видеокарты ответ будет идти десятки секунд.
2. Настройки → «Модель» → пресет **«Локальная модель»**: адрес `http://localhost:1234`,
   имя модели `gpt-oss`. Поправьте порт и имя под свой сервер, ключ не нужен.
3. **«Проверить подключение»** — один короткий запрос покажет время ответа или ошибку.

Таймаут разбора — 90 секунд. Если модель не укладывается, возьмите поменьше.

### Облачная модель: ключ провайдера

1. Настройки → «Модель» → выберите вид API и пресет. OpenAI-совместимые облака —
   Yandex AI Studio, OpenAI, OpenRouter, Groq, DeepSeek, Mistral — кнопками, Anthropic
   и Google Gemini — переключателем вида API (он перезаписывает адрес и модель).
2. Вставьте ключ из кабинета провайдера.
3. **«Проверить подключение».**

Разбор страницы — один запрос на несколько тысяч символов текста, поэтому счёт
получается небольшой даже у платных моделей. Дешёвые ориентиры: `gpt-4o-mini`,
`deepseek-chat`, `mistral-small`, `yandexgpt-lite`; у OpenRouter и Groq есть модели
с бесплатным лимитом — смотрите условия у них, они меняются.

### Включить модель

Настройки → «Чтение» → «Кто ищет сложные слова» → **Языковая модель**. Там же
**«Уточнение к промпту»** — свободный текст, который уходит модели вместе с правилами
расширения: «имена и названия не разбирай, перевод давай разговорный, термины
объясняй подробнее».

### Что происходит с переводом

Словарь из варианта 1 никуда не девается: одиночные слова по-прежнему переводятся
им — быстрее и дешевле, а модель берёт фразы и всё, чего словарь не знает.
«Не переводить» в списке источников отдаёт модели всё.

## Что выбрать

| | Бесплатно | Локальная модель | Облачная модель |
| --- | --- | --- | --- |
| Настройка | ничего | сервер на компьютере | ключ провайдера |
| Стоимость | 0 | 0, но железо | копейки за страницу |
| Находит | отдельные слова | слова и фразы в контексте | слова и фразы в контексте |
| Языки чтения | английский | любой | любой |
| Пояснения | нет | есть | есть |
| Скорость | мгновенно | зависит от железа | секунды |

Начните с бесплатного варианта: если список слов на ваших страницах устраивает,
модель не нужна. Переключиться можно в любой момент, словарь и прогресс тренировки
от этого не зависят.
