## Начало работы

### Что это и чем оно отличается от переводчика страницы

Переводчик подменяет оригинал целиком, и язык, который вы учите, читать перестаёте.
Словарь по клику переводит всё, по чему щёлкнули, включая сотню слов, которые вы и так
знаете. Erudit не делает ни того ни другого: текст остаётся нетронутым, а подсвечиваются
только слова и фразы выше вашего уровня. Их можно сохранить в словарь, повторять
по расписанию и выгрузить в Anki.

### Нужен ли ключ, аккаунт или деньги

Нет. Из коробки слова отбирает встроенный офлайн-профиль CEFR (8833 английские записи),
а переводит их бесключевой MyMemory. Ни регистрации,
ни платежей, ни своего сервера у расширения нет.

Языковая модель — улучшение, а не условие запуска: она находит ещё и фразы, видит контекст
и умеет объяснять. Подключается своим ключом или своей локальной моделью.

### Как установить

В магазинах расширения пока нет, оно собирается из исходников (нужен Node.js 20+):

```bash
git clone https://github.com/Hakoba/erudit
cd erudit
npm install
npm run build
```

**Chrome:** `chrome://extensions` → включить режим разработчика → «Загрузить распакованное
расширение» → выбрать `dist/chrome`.

**Firefox:** `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» →
выбрать любой файл внутри `dist/firefox`. Временные дополнения Firefox забывает
при перезапуске.

После установки откроется страница настройки: уровень и языковая пара, список сайтов,
ссылка на демо-страницу.

### Почему на сайте ничего не происходит

Расширение работает **только на сайтах из вашего списка** и больше нигде. По умолчанию
там один адрес — `https://www.reddit.com/`.

Добавить текущий сайт быстрее всего из попапа расширения: кнопка «Разрешить `<домен>`».
После добавления **страницу нужно перезагрузить** — content script монтируется при загрузке
документа.

Список правится в настройках, раздел «Сайты». Правила адресов:

- адрес целиком, с протоколом; `http://` и `https://` — разные адреса;
- `www.` игнорируется: `reddit.com` покрывает и `www.reddit.com`;
- поддомены — звёздочкой: `https://*.reddit.com`;
- путь работает как префикс: `https://site.com/books/` включит всё внутри;
- переключатель у записи выключает сайт временно, не удаляя его.

### Где искать интерфейс расширения

Зависит от браузера — модели боковых панелей у них разные.

**Chrome.** Список слов живёт в боковой панели браузера. Открыть её можно тремя способами:
ярлык-закладка у правого края страницы, кнопка «Открыть боковую панель» в попапе или
горячая клавиша `Ctrl+Shift+E` (`⌘+Shift+E` на маке). Сочетание переназначается
в `chrome://extensions/shortcuts`.

Сама панель открыться не может — Chrome разрешает это только в ответ на действие
пользователя. Пока она открыта, ярлык на странице прячется. Закрыть панель горячей
клавишей нельзя: в Chrome нет такого API, только крестик самой панели.

Панель следит за активной вкладкой: переключились — увидели разбор новой страницы.

**Firefox.** Панель прижата к правому краю самой страницы (380 px), и страница ужимается
ровно на её ширину. Есть кнопка «Свернуть» — панель превращается в узкий рельс (48 px)
со счётчиком и кнопкой «Перечитать». Свёрнутое состояние глобальное: свернули один раз —
на новых вкладках панель сама не развернётся.

В обоих браузерах на значке расширения горит бейдж с числом найденных слов для текущей
вкладки.

### Что в шапке панели

Счётчик найденных слов, «Перечитать страницу», «Мой словарь», «Подмена слов»
(подсвечивается, когда включена), «Забыть выбранную область» (только если область выбрана),
«Выбрать область с текстом», «Настройки». В доке Firefox добавляются «Свернуть» и «Закрыть»
(закрытие — до перезагрузки страницы).

## Кто ищет слова: профиль или модель

Настройка «Чтение» → «Кто ищет сложные слова». По умолчанию — офлайн-профиль.

| | Офлайн-профиль CEFR | Языковая модель |
| --- | --- | --- |
| Настройка | не нужна, работает сразу | адрес модели, в облаке ещё и ключ |
| Цена | бесплатно | по тарифам провайдера, локально бесплатно |
| Находит | отдельные слова, до 25 на страницу | слова и фразы, с учётом контекста |
| Пояснения | нет | по кнопке, отдельным запросом |
| Языки | только английский | любые |

**Офлайн-профиль** собирает из текста уникальные слова, ищет каждому уровень во встроенном
списке, отбрасывает всё ниже вашего уровня, сортирует от самого сложного и оставляет
не больше 25. Перевод к ним даёт словарь; слово, которого словарь не знает, останется
без перевода, но с уровнем и подсветкой. Имена, термины и опечаток в профиле нет —
они просто не попадут в список.

**Модель** получает текст и порог уровня прямо в запросе. Для английского её ответ
дополнительно просеивается тем же офлайн-списком: слова ниже вашего уровня выбрасываются,
а словам без уровня уровень подставляется из списка.

Без модели в любом режиме продолжают работать: подсветка сохранённых слов, карточки
при наведении, словари и внешние ссылки, подмена слов и перевод выделенного текста.

## Уровень CEFR

### Что меняет «Мой уровень»

Шкала A1–C2, по умолчанию B1. Слова ниже вашего уровня расширение не трогает вовсе —
предполагается, что вы их знаете. Поставили B2 — в списке останутся только C1 и C2;
поставили C1 — страница почти замолкает.

Уровень и языки уходят **в сам запрос**, а не фильтруют готовый ответ, поэтому смена
видна со следующего разбора страницы, а не задним числом.

### Почему уровни работают только для английского

Встроенный список уровней собран из двух открытых профилей — CEFR-J (A1–B2) и Octanove
(C1/C2), — и оба про английский. Профилей такого качества для других языков в открытом
доступе не нашлось.

Практические следствия: при чтении не с английского режим «офлайн-профиль» не работает
и прямо об этом говорит, а слова, переведённые словарём, остаются без уровня — для них
на экране словаря есть отдельный фильтр «Без уровня». Модель уровень ставит сама
на любом языке.

### Почему в списке простое слово

Формы слов снимаются правилами, а не лемматизатором: окончания `-s/-es/-ies/-ed/-ing/-er/-est/-ly`
и удвоенная согласная (`stopped` → `stop`). Неправильные глаголы правила не покрывают:
`saw` до `see` не сводится, слово не находится в списке и проходит дальше как незнакомое.
Примерно одно лишнее слово из десяти в режиме без модели.

Лечится кнопкой «Скрыть слово» — она убирает слово из списка и из подсветки навсегда.

При отборе у слова берётся **самый низкий** уровень среди всех его форм: `known` считается
за `know`, потому что знающий глагол не споткнётся о причастие.

### Как убрать слово навсегда

Кнопка с перечёркнутым глазом в строке слова. Такие слова живут в отдельном списке,
не в словаре: в словаре они попали бы в тренировку и в экспорт. Вернуть их можно внизу
экрана словаря, блок «Скрытые слова».

## Чтение страницы

### Когда запускается разбор

По умолчанию — сам, при открытии страницы. Если выключить «Разбирать страницу сразу
при открытии», вместо списка появится кнопка «Разобрать страницу», а подсветка сохранённых
слов и карточки при наведении продолжат работать.

Разбор запускается заново при выборе области, сбросе области и переключении подмены
слов.

### На что уходят запросы и как их беречь

Открыта панель или закрыта — не важно: разбор живёт на самой странице, панель только
показывает результат. Запросы уходят переводчику, словарю толкований или модели
(токены). Что их экономит:

- **Фоновая вкладка ничего не тратит.** Страница, открытая через Ctrl+клик, ждёт первого
  показа и только тогда идёт в словарь или модель.
- **Выключенный автозапуск** (см. выше): разбор только по кнопке.
- **Дописанное, а не вся страница.** Читалка догрузила главу — в запрос уходит только
  хвост, прежний текст не пересылается.
- **Пакетный перевод.** Google, Azure и DeepL переводят все найденные слова одним
  запросом; MyMemory, Lingva и LibreTranslate — по запросу на слово.
- **Кэш словарей** до перезагрузки страницы: одно слово спрашивают один раз.
- **Задержка 400 мс** при наведении и режим «Показать кнопку, перевод по клику»
  для выделения.

Самый дорогой запрос — «Пояснение модели» в карточке: он всегда по кнопке.

### Что значат цвета подсветки

- **Жёлтый** — найденное сложное слово, которого ещё нет в словаре.
- **Зелёный** — слово из вашего словаря. Подсвечивается всегда, даже если разбор
  не запускали.
- **Синяя вспышка на полсекунды** — переход к слову из списка.

Сохранили слово — оно тут же становится зелёным, без перезагрузки. Подсветка не добавляет
в документ сайта ни одного CSS-класса, только инлайновые стили, и обходит скрытые элементы,
навигацию, код и содержимое `script`/`svg`/`canvas`.

### Что показывает карточка при наведении

Слово, уровень CEFR, транскрипцию, перевод и до двух толкований с частью речи и примером.
Внизу — «Найдено на этой странице» либо «Уже в словаре, повтор через N дней».

Запрос в словари уходит через 400 мс после наведения, чтобы курсор, пробегающий по тексту,
не дёргал словари зря; ответы кэшируются до перезагрузки страницы. Карточка сквозная —
мышь она не перехватывает, ткнуть в неё нельзя (исключение — карточка подменённого слова,
у неё есть кнопки).

### Как найти слово в тексте

Клик по слову в списке или иконка-прицел прокручивают страницу к вхождению и подсвечивают
его синим. Повторный клик ведёт к следующему вхождению, по кругу.

Кнопки перехода нет, если слова в тексте не нашлось: модель иногда отвечает начальной
формой (`ran` → `run`), которой на странице нет.

### Расширение разбирает не тот блок

Текст ищется по трём источникам в порядке убывания доверия:

1. Область, которую вы выбрали руками.
2. Встроенное правило для сайта — есть для reddit (пост и каждый комментарий),
   webnovel и royalroad, работают и на поддоменах.
3. Общий алгоритм: типовые контейнеры (`article`, `main`, `.post-content`,
   `.chapter-content` и подобные) плюс любой блок минимум с тремя абзацами, из них
   выбирается тот, где больше текста и меньше ссылок. Так отсекаются меню
   и «читайте также».

Если промахнулся — кнопка «Выбрать область с текстом». Панель свернётся, чтобы отдать
тексту ширину, экран затемнится кроме блока под курсором, у блока будет ярлык
вида `div.chapter · 4230 симв.`. Клик выбирает блок, `Esc` отменяет.

Выбор запоминается **не для одного адреса, а для страниц одного вида**: путь обрезается
до первого сегмента с цифрой или до последнего сегмента, если он не единственный
(`/news/some-title/` → `/news/`). Область, выбранная на одной статье, работает на всех
статьях раздела, но не на ленте и не на главной: у них свои записи, и сброс ластиком
снимает область только с текущего вида страниц.

Правило для сайта, на котором расширение промахивается, — самый полезный вклад
из дешёвых: это хост и список селекторов в `src/utils/extract/rules.ts`.

### Страница дописала текст — почему список прежний

При обычном разборе расширение сравнивает текст с прошлым и отдаёт в работу **только
дописанное**: на читалках текст дописывается в конец, и разбирать страницу целиком заново
было бы и дорого, и бессмысленно. Если дописанного нет, разбор ничего не трогает —
на пустом экране он объяснит, почему список пуст, а готовый список оставит как есть.

Кнопка **«Перечитать страницу»** читает страницу с нуля и собирает список заново —
она же выручает, когда автоматический разбор поймал не тот момент.

Ограничение на объём: в один разбор уходит не больше 8000 символов, обрезка идёт с конца
(то есть у догруженного куска берётся его начало). Строки короче 30 символов и повторы
абзацев отбрасываются.

### Переход на другую страницу внутри сайта

Reddit и читалки меняют страницу, не перезагружая документ. Своего события у такого
перехода нет, поэтому адрес опрашивается раз в полсекунды; после смены расширение ждёт
700 мс, чтобы сайт успел подставить текст, и разбирает новую страницу с чистого листа.

На медленном соединении разбор может застать предыдущий текст или пустую страницу —
на этот случай есть «Перечитать страницу».

### Пояснение модели — платное?

Раскрытие карточки «Подробнее» бесплатно: там ответы словарей и внешние ссылки.
Модель зовёт только кнопка «Пояснение модели», отдельным запросом с контекстом страницы.

## Выделение текста

Настройка «Чтение» → «Когда выделяешь текст», четыре режима:

| Режим | Что происходит |
| --- | --- |
| **Показать перевод** (по умолчанию) | Карточка с переводом появляется сразу; запрос уходит на каждое выделение, включая случайное |
| **Показать кнопку, перевод по клику** | Рядом появляется кнопка с логотипом — предохранитель от случайных запросов |
| **Сразу добавить в словарь** | Одна кнопка: переводит и сохраняет одним действием, перевод не показывая |
| **Ничего не делать** | Выделение игнорируется |

Выделение длиннее 200 символов игнорируется — это уже абзац, а не слово или фраза.
Вместе со словом сохраняется предложение из ближайшего абзаца (до 300 символов).

Одиночное слово переводит словарь, фразу — машинный переводчик или модель. Уровень CEFR
ставит только модель.

## Подмена слов

Обратная задача: не вы читаете иностранный текст, а знакомые слова встречают вас
на родном. На странице **на языке перевода** отдельные слова подменяются словами
из вашего словаря; при наведении карточка показывает оригинальную словоформу и спрашивает
«Знал / Не знал», а ответ двигает интервальное повторение так же, как тренировка.

Включается настройкой в «Чтении» или кнопкой в шапке панели. Выключение возвращает
оригиналы сразу, без перезагрузки. Работает полностью офлайн: только ваш словарь,
без модели и внешних словарей.

Как отбираются слова: не больше 15 на страницу, по одному на предложение, каждая запись
один раз; в первую очередь те, что пора повторять по SRS, затем ни разу не тренированные.
Замена не трогает ссылки, код и редактируемые поля.

**Когда режим молчит.** Язык страницы определяется по письменности: доля букв нужной
письменности среди первых 3000 должна превышать 60 %. Поэтому пары с общей письменностью
(английский → испанский) не различаются, и режим просто не срабатывает — ложное молчание
дешевле ложной замены. Работают пары, где письменности разные: латиница против кириллицы,
японской, китайской или корейской.

Совпадение словоформы с переводом ищется по общей основе (общий префикс от 4 букв,
хвосты до 3) — это заменяет морфологию для русских окончаний. Супплетивные формы
(«люди» ↔ «человек») не находятся.

## Словарь

### Как слово туда попадает

1. Кнопка-закладка в строке слова — сохраняет слово, перевод, уровень, предложение-контекст
   и пояснение, если его успели раскрыть.
2. «Добавить все — N» над списком. Пояснений у таких записей не будет.
3. Выделение текста на странице — по правилам режима выделения.
4. Ручная форма на экране словаря. Кнопка «Из словаря» подставит перевод из Яндекс.Словаря,
   не зовя модель.
5. Импорт колоды `.apkg` из Anki.

Дубли не создаются: сравнение идёт по нормализованному слову (регистр и лишние пробелы
не важны). Повторное добавление обновляет запись, а удалённую — воскрешает вместе
с прогрессом тренировки.

### Что хранится в записи

Слово, перевод, предложение-контекст, пояснение, уровень CEFR, даты добавления
и изменения, а также состояние повторений: когда показать, шаг лестницы интервалов,
сколько раз повторяли и сколько раз ошиблись.

Откуда слово пришло — сайт, заголовок, ссылка — **не хранится**, поэтому фильтра «слова
из этого источника» нет. Это осознанное упрощение, оно записано в `deferred.md`.

### Что есть на экране словаря

Поиск сразу по четырём полям (оригинал, перевод, контекст, пояснение), фильтр по уровню
(список собирается только из тех уровней, что реально есть), переключатель «С пояснением»,
сортировки «Сначала новые / Сначала старые / По алфавиту», пагинация по 20 записей.
Перевод правится прямо в строке, остальные поля — нет.

Кнопка **«Дозаполнить переводы»** появляется в шапке, когда в словаре есть слова без
перевода — обычно они попадают туда, если источник в тот момент молчал: не знал слова,
отказал по ключу или упёрся в квоту. По нажатию расширение спрашивает перевод у того
источника, который выбран сейчас, пачками по пять слов; сколько получилось и сколько
осталось, оно пишет по окончании. Общий отказ (кончившаяся квота, отклонённый ключ)
останавливает проход и показывает причину — уже переведённые слова при этом сохраняются.

Удаление **мягкое**: запись уходит в блок «Удалено недавно», откуда возвращается вместе
с прогрессом тренировки. Кнопка «Очистить» стирает эти надгробия окончательно.

Ниже — блок скрытых слов, оттуда они возвращаются по клику.

### Где словарь лежит и сколько влезет

В локальном хранилище браузера (`storage.local`), лимит около 10 МБ — это тысячи слов
с контекстом. На сервер расширения ничего не уходит, потому что сервера нет.

Удаление расширения или очистка данных браузера уносит словарь с собой. Резервная
копия — раздел «Копия» в настройках: он сохраняет словарь и настройки одним `.json`.

### Синхронизируется ли словарь между устройствами

Нет. Синхронизируются только настройки: уровень и языки, подключение модели, ключи
словарей, список сайтов. Словарь, скрытые слова, выбранные области и тема остаются
на этом компьютере.

Причина: у синхронизируемого хранилища лимит 100 КБ на всё и 8 КБ на запись — пара сотен
слов с предложениями туда не влезает.

Перенести всё вручную можно файлом резервной копии: раздел «Копия» в настройках,
«Сохранить в файл» на одном компьютере и «Загрузить из файла» на другом. В `.json`
уходят оба хранилища целиком — словарь с прогрессом повторений, скрытые слова,
выбранные области и настройки вместе с ключами (поэтому файл не стоит выкладывать
в открытый доступ).

Только словарь переносит Anki: экспорт `.apkg` на одном компьютере, импорт «Из Anki»
на другом. Переедут слово, перевод, контекст и уровень; пояснения и прогресс
повторений — нет.

## Тренировка

«Тренировка» — отдельный пункт в меню страницы расширения, рядом со «Словарём». Карточка
показывает слово и предложение-контекст, перевод открывается по кнопке, оценок две —
«Знал» и «Не знал».

**Лестница интервалов: 1, 3, 7, 16, 35, 90 дней.** Верный ответ двигает на шаг вверх,
после 90 дней интервал больше не растёт. Ошибка сбрасывает лестницу **целиком в начало**,
а не на шаг назад. Ease-фактора, как в Anki, здесь нет — расписание намеренно простое.

В очередь попадают слова, у которых подошёл срок, плюс все ни разу не тренированные —
они идут первыми. Размер сессии — 20 слов, в настройки не вынесен; после сессии можно
сразу взять следующую пачку.

**Клавиатура:** пробел или Enter — показать перевод, `1` — «не знал», `2` — «знал»,
Enter на пустом экране — следующая пачка.

Второй способ повторять — [подмена слов](#подмена-слов): она двигает те же
интервалы. И подсказка при наведении на зелёное слово на странице говорит, через сколько
дней его повторять.

## Anki

### Экспорт

Настоящий файл `.apkg` (zip с базой SQLite схемы 11 — её понимают все версии Anki 2.1+),
собирается прямо в браузере. Имя файла — `erudit-ГГГГ-ММ-ДД.apkg`.

Выгружается **то, что сейчас видно на экране с учётом фильтров** — кнопка так и подписана.
Удалённые и скрытые слова не попадают.

Колода — «Erudit», тип заметки — «Erudit — слово», четыре поля: слово, перевод, контекст,
пояснение. Уровень CEFR уходит в теги. Идентификатор заметки берётся из id записи, поэтому
повторный экспорт **обновляет заметки, а не плодит дубли**, и всегда попадает в ту же колоду.

Прогресс повторений Erudit в колоду не переносится: карточки уезжают новыми, расписание
Anki ведёт своё.

### Импорт

Кнопка «Из Anki», файл `.apkg`. Берутся первые два поля заметки — слово и перевод,
третье, если есть, — контекст; уровень подхватывается из тегов. Так устроен и наш экспорт,
и типовая чужая колода «слово → перевод». HTML из чужих колод вычищается. Дубли
не создаются, итог показывается сообщением «Добавлено слов: N, уже было: M».

**Ограничение:** читаются `collection.anki2` и `collection.anki21`. Новый формат
`collection.anki21b` (Anki 2.1.50+, сжатие zstd) не поддержан — экспортируйте колоду
из Anki с галкой «Поддержка старых версий».

Экспорта в CSV или JSON нет, `.apkg` — единственный формат выгрузки.

## Подключение модели

Настройки → «Модель». Поддержаны три семейства API:

| Вид API | Кто это | Ключ |
| --- | --- | --- |
| **OpenAI-совместимый** | локальные серверы (LM Studio, Ollama, llama.cpp) и облака: Yandex AI Studio, OpenAI, OpenRouter, Groq, DeepSeek, Mistral | локально не нужен, в облаке обязателен |
| **Anthropic** | Claude, формат Messages | обязателен |
| **Google Gemini** | Gemini | обязателен |

Кнопки-пресеты подставляют адрес и имя модели, ключ вводится отдельно:

| Пресет | Адрес | Модель |
| --- | --- | --- |
| Локальная модель | `http://localhost:1234` | `gpt-oss` |
| Yandex AI Studio | `https://llm.api.cloud.yandex.net` | `gpt://<каталог>/yandexgpt-lite/latest` |
| OpenAI | `https://api.openai.com` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api` | `openai/gpt-4o-mini` |
| Groq | `https://api.groq.com/openai` | `llama-3.3-70b-versatile` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| Mistral | `https://api.mistral.ai` | `mistral-small-latest` |

Осторожно: **смена «Вида API» перезаписывает адрес и модель и стирает ключ** — чужие
значения в другом протоколе всё равно не работают. Пресеты внутри одного вида API ключ
не трогают.

**«Проверить подключение»** шлёт один короткий запрос и показывает время ответа либо ровно
ту ошибку, которую увидел бы оверлей. Проверяет адрес, ключ и имя модели разом, стоит долю
копейки.

Оранжевая точка у пункта «Модель» в меню значит, что адрес облачный, а ключ пуст.
Для локальных адресов (`localhost`, `127.0.0.1`, `[::1]`, `*.local`) она не загорается.

**Таймаут — 90 секунд**: локальные модели на процессоре думают долго.

**Уточнение к промпту** (раздел «Чтение») — свободный текст до 500 символов, уходит модели
вместе с нашими правилами. Годится для жанра, имён и манеры перевода: «это тёмное фэнтези,
имена и топонимы не разбирай, перевод давай разговорный». Формат ответа задаёт расширение,
уточнением его не сломать.

## Словари и переводчики

Кто переводит слова и фразы до модели, решает один список — «Настройки → Словари
и переводчики → Чем переводить». В нём Яндекс.Словарь стоит наравне с машинными
переводчиками, поля под ключ, адрес сервера или почту появляются под списком после
выбора. Модель подключается только к тому, что выбранный источник не осилил.

**Яндекс.Словарь** даёт перевод, несколько значений и транскрипцию, но знает лишь
одиночные слова — фразы при нём уходят к модели. Ключ нужен свой: новые Яндекс больше
не выдаёт (форма выдачи ведёт на страницу обратной связи), так что пункт остался для тех,
у кого ключ уже есть. Общего ключа в сборке нет.

**Карточка слова** переводит тем же источником, что и разбор: машинный переводчик даёт
один перевод без транскрипции и частей речи, Яндекс.Словарь — полную статью. Толкования
на языке оригинала приходят из dictionaryapi.dev в любом случае.

**dictionaryapi.dev** отдаёт толкования на языке оригинала, транскрипцию и примеры,
без всякого ключа. Его зовут карточка при наведении и раскрытая панель «Подробнее»;
при разборе страницы целиком он не дёргается.

**Машинные переводчики** берут и слова, и фразы. Google Translate, Azure и DeepL
переводят найденные разбором слова одним запросом; MyMemory, Lingva и LibreTranslate
пакета не умеют и получают по запросу на слово. По умолчанию выбран **MyMemory** —
единственный бесключевой с официальным тарифом; бесключевых с пакетом не осталось:
точку токена Edge Microsoft закрыл, а Google банит по частоте. «Не переводить»
отдаёт всё модели. Машинный переводчик дешевле и быстрее модели, но не видит контекста
и не ставит уровень; уровень CEFR не ставит и Яндекс.Словарь. Поля под ключ, адрес сервера или почту появляются под
списком после выбора — у каждого переводчика свои.

Без ключа и регистрации работают три:

| Переводчик | Лимит | Чем платить |
| --- | --- | --- |
| **MyMemory** | 5 000 слов в сутки на адрес, 50 000 — если указать почту | ничем, лимит официальный |
| **Google Translate** | не объявлен | эндпоинт неофициальный |
| **Lingva** | зависит от инстанса | прокси к Google, держат добровольцы |

MyMemory — единственный из них с документированным бесплатным тарифом. Почта в настройках
поднимает суточную квоту вдесятеро и ключом не считается; кончившуюся квоту сервис отдаёт
не ошибкой, а предупреждением на месте перевода — расширение такой ответ переводом не считает.

Google и Lingva ходят во внутренние эндпоинты чужих веб-клиентов: ключа они не просят,
но могут начать отказывать или пропасть в любой день — настройки об этом предупреждают.
Переводчик Edge из списка убран: Microsoft закрыл точку выдачи токена. DeepL из России
отвечает 451 и не работает без VPN. Для Lingva нужен адрес инстанса
(по умолчанию `lingva.ml`), актуальный список — в
[репозитории проекта](https://github.com/thedaviddelta/lingva-translate#instances).

С ключом, но бесплатно, работают ещё три:

**DeepL** — 500 000 символов в месяц на бесплатном тарифе, качество лучшее из списка.
Ключ бесплатного тарифа оканчивается на `:fx`, по нему запросы автоматически идут
на бесплатный эндпоинт.

**Azure Translator** — 2 миллиона символов в месяц на тарифе F0. Кроме ключа нужен регион
ресурса (`westeurope`, `eastus`); у ресурса Global поле остаётся пустым.

**LibreTranslate** — свой либо публичный сервер, адрес задаётся в настройках.
На своём сервере обычно обходится без ключа.

В режиме «офлайн-профиль» модель не подключается вовсе: при «Не переводить» слова
останутся с уровнем и подсветкой, но без перевода.

Отказ переводчика список слов не отменяет: слова находит офлайн-профиль, уровень
и подсветка от перевода не зависят. Они останутся на экране, а причина покажется
сообщением рядом со списком.

**Внешние ссылки** в панели «Подробнее» — просто адреса, без запросов: Google Translate,
Яндекс.Переводчик, Reverso Context, Мультитран (только для пары английский → русский)
и Wiktionary.

Ответы словарей кэшируются в памяти вкладки: одно слово за страницу спрашивают многократно,
а запрос уходит один. После перезагрузки страницы кэш пуст.

## Приватность

**Своего сервера у расширения нет.** Текст страницы уходит только туда, куда вы сами
указали: на ваш локальный сервер модели, к выбранному облачному провайдеру или в словари.
Никакой аналитики, телеметрии и аккаунтов.

**Ключи** лежат в синхронизируемом хранилище браузера вместе с остальными настройками —
значит, они уезжают в ваш аккаунт браузера и появляются на других устройствах, где вы
вошли в тот же профиль. В коде, в репозитории и в сборке ключей нет.

**Что видит владелец сайта:** ничего сверх обычного визита. Расширение не отправляет
никаких данных на посещаемый сайт и не трогает его запросы.

### Как выбрать, где расширению работать

На экране «Сайты» — и сразу после установки, на экране приветствия, — два режима. **«Только на этих»** — как из коробки: расширение молчит
везде, кроме перечисленного (по умолчанию там `reddit.com`). **«Везде, кроме этих»** —
наоборот: включается на любом сайте, а список становится списком исключений.

У режимов свои списки, поэтому переключение туда и обратно ничего не стирает.

В режиме «везде, кроме» расширение само обходит стороной почту, банки, госуслуги
и внутренние адреса — даже если их нет в исключениях. Правило смотрит на имя хоста
(`mail.*`, метка `gov`, слово `bank`, адрес без точки), а не на список доменов: банков
и почтовых сервисов в мире слишком много, чтобы их перечислять. Оно намеренно грубое —
сайт со словом «bank» в имени попадёт под него заодно, — поэтому рядом стоит галочка,
которой защиту можно снять целиком.

Снимать её целиком ради одного сайта не нужно: откройте попап расширения **на самом
сайте** и нажмите «Всё равно включить». Адрес попадёт в исключения из защиты — правило
продолжит беречь всё остальное, а этот сайт больше не трогает. Список исключений виден
на экране «Сайты» под галочкой, оттуда же запись убирается, и защита возвращается.
Исключение не спорит с чёрным списком: адрес, внесённый в «Везде, кроме этих»,
останется выключенным.

**Разрешения манифеста:**

- `storage` — настройки и словарь;
- `tabs` — адрес активной вкладки для кнопки «Разрешить домен» и для боковой панели;
- `scripting` — подключение скрипта расширения к сайтам, к которым выдан доступ;
- доступ к сайтам — из коробки только `reddit.com` и бесключевые словари
  (dictionaryapi.dev и MyMemory). Каждый следующий сайт,
  переводчик или адрес модели вы разрешаете сами: браузер спрашивает при добавлении
  сайта, выборе переводчика или пресета модели. Режим «везде, кроме» просит доступ
  ко всем сайтам один раз.

Список сайтов синхронизируется между устройствами, а разрешения браузера — нет:
на новом устройстве у таких сайтов появится кнопка «Дать доступ» — в попапе,
в боковой панели и в списке сайтов. Отозвать доступ можно на странице расширения
в `chrome://extensions` («Доступ к сайтам»).

Все запросы наружу идут через фоновый скрипт — иначе со https-страницы не достучаться
до локальной модели по http, а CSP сайта режет запросы к чужим доменам. В лог пишется
адрес без query: у словарей ключ лежит прямо в адресе.

## Если что-то пошло не так

**«На странице не нашлось текста для разбора»** — алгоритм не нашёл блок с текстом.
Укажите его руками: «Выбрать область с текстом».

**«Новый текст на странице пока не появился»** — весь текст уже разобран. Если страница
дописала текст, а расширение этого не заметило, нажмите «Перечитать страницу».

**«Модель не ответила за 90 секунд»** — обычно локальная модель на процессоре. Возьмите
модель поменьше или проверьте, что сервер не занят.

**«... отклонил ключ API»** — ключ неверен, истёк или не от того провайдера. Проверьте
ключ и имя модели кнопкой «Проверить подключение».

**«... не знает такой эндпоинт или модель (404)»** — опечатка в адресе или в имени модели.
У Яндекса имя выглядит как `gpt://<каталог>/yandexgpt-lite/latest`.

**«Не удалось подключиться»** — сервер модели не запущен или адрес недоступен.
Для локальной модели проверьте, что сервер слушает указанный порт.

**«Яндекс.Словарь отклонил ключ»** — ключ неверен или отозван; сервис на это отвечает 403.
Новых ключей Яндекс не выдаёт — переключите «Чем переводить» на машинный переводчик.

**«Офлайн-профиль CEFR собран только по английскому»** — вы читаете не на английском.
Переключите «Кто ищет сложные слова» на модель.

**«Колода в новом формате Anki»** — экспортируйте её из Anki с галкой «Поддержка старых
версий».

**«Erudit не работает на этой странице»** в боковой панели — сайта нет в списке
разрешённых (или, в режиме «везде, кроме», он как раз в списке) либо страницу
не перезагрузили. Кнопка на этом экране подписана под ситуацию: «Разрешить `<домен>`»
добавляет сайт, «Вернуть `<домен>`» убирает его из исключений, и обе сами перезагружают
вкладку; «Перезагрузить страницу» появляется, когда доступ уже есть. Оттуда же
открываются настройки.

**Панель пустая, а на странице ничего не подсвечено** — проверьте, что сайт разрешён,
и перезагрузите страницу. Если это dev-сборка, а вы только что пересобрали расширение,
его нужно перезагрузить в `chrome://extensions`.

## Известные ограничения

Сознательные упрощения с условиями, при которых к ним стоит вернуться, собраны
в [deferred.md](../deferred.md). Коротко о том, что заметно при обычном чтении:

- **Firefox: элементы сайта с `position: fixed`** (шапки, плавающие кнопки) считают
  ширину от окна и заезжают под док. В Chrome этого нет — там вьюпорт ужимает сам браузер.
- **Карточка у верхней кромки экрана** не переворачивается вниз и может уехать за экран.
- **Неправильные глаголы** не сводятся к начальной форме: изредка простое слово попадает
  в список.
- **Офлайн-режим не видит фраз** — только отдельные слова: списка идиом с уровнями
  в открытом доступе нет.
- **Уровни CEFR только для английского**, для остальных языков нужна модель.
- **Подмена слов не работает для пар с общей письменностью** (английский → испанский).
- **Словарь не синхронизируется** между устройствами; перенос — файлом через Anki.
- **Источник слова не хранится**: нельзя отфильтровать «слова из этого источника».
- **Догрузка по скроллу без смены адреса** разбор не запускает — выручает «Перечитать
  страницу».
- **Anki `collection.anki21b`** (zstd) при импорте не поддержан.
