MVP функционал расширения (коротко и по делу):

Работает только на novelbin.com
При загрузке главы автоматически парсит текст (по умолчанию — только видимую часть, в настройках можно переключить на всю главу).
Отправляет текст в LLM → получает список сложных слов и фраз для уровня B1 с переводом на русский и кратким объяснением.
Отображает результат в Shadow DOM карточке, закреплённой вверху страницы (не ломается стилями сайта).
При выделении любого текста на странице появляется плавающая кнопка «Сохранить в словарь» → сохраняет выделенное в личный словарь.
Словарь — доступен в popup расширения: список всех сохранённых слов/фраз, поиск, удаление, редактирование. Синхронизируется между устройствами через chrome.storage.sync.
Настройки (options page):
Режим парсинга: только видимый текст / вся глава
Вкл/выкл авто-анализа главы
(задел на будущее) выбор LLM-провайдера

Всё на Vue 3 + Vite + Manifest V3, без iframe’ов, чистый Shadow DOM для UI на странице.

Не в MVP: экспорт в Anki, подсветка уже известных слов, многоязычность, определение уровня пользователя динамически.
