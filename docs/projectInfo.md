# Novel Translator — состояние проекта

Расширение помогает читать англоязычные новеллы: разбирает главу через локальную LLM,
показывает сложные слова уровня B1 с переводом и подсвечивает их в тексте.

## Готово

- **Список разрешённых сайтов** (`useAccessSites`, `storage.sync`, по умолчанию `novelbin.com`).
  Content script монтируется только на разрешённых адресах. Матчинг адресов — `matchesSite`,
  покрыт тестами (протокол, хост, `*.` поддомены, префикс пути).
- **Оверлей главы** в Shadow DOM: собственный контейнер справа снизу, сворачивание, закрытие.
  Стили инлайнятся внутрь shadow root, стили PrimeVue зеркалятся из `document.head`
  (`mirrorStyles.ts`) — документ сайта не трогаем.
- **Запрос к LLM** через background-прокси (`bgFetch` → `browser.runtime.sendMessage`):
  content script не может ходить на http-эндпоинт со https-страницы, service worker может.
- **Разбор ответа модели** (`llmParse.ts`): переживает markdown-фенсы и рассуждения вокруг
  JSON, тесты в `llmParse.test.ts`.
- **Пояснение к слову** по клику (отдельный запрос к модели с контекстом главы).
- **Подсветка найденных слов** в тексте страницы (`highlight.ts`, инлайновые стили).
- **Настройки** (options page): адрес сервера модели и имя модели, список сайтов, тема.
- **UI**: PrimeVue + Tailwind 4, компоненты автоимпортируются, тема через класс `.dark`.

## В работе / дальше

1. **Словарь.** Кнопка «в словарь» в `WordItem` пока заглушка. Нужен стор в `storage.sync`,
   список в popup с поиском, удалением и редактированием.
2. **Сохранение выделенного.** Плавающая кнопка при выделении текста на странице →
   сохранить фразу в словарь.
3. **Яндекс.Переводчик** для отдельных слов: ключ API в настройки, запрос через тот же
   background-прокси, выбор провайдера перевода.
4. **Экспорт в Anki**: начать с CSV (`.apkg` дороже и требует генерации SQLite).
5. **Режимы парсинга**: только видимая часть / вся глава, вкл-выкл авто-анализа.

## Ограничения и решения

- **Shadow DOM обязателен.** Раньше content script импортировал глобальный `base.css`
  с Tailwind-preflight — это ломало вёрстку сайта. Никакого глобального CSS в документ.
- **PrimeVue Dialog в оверлее не используется**: он телепортируется в `document.body`,
  то есть за пределы shadow root, и остаётся без стилей. Панель свёрстана вручную.
- **PrimeVue 4.5 не умеет `styleContainer`** — отсюда зеркалирование стилей из head.
- **Ключи и адреса — только в настройках**, не в коде: репозиторий публичный.
