# Режим вкраплений (immersion mode)

## Why

Erudit помогает только при чтении на изучаемом языке, а большую часть времени
пользователь читает на родном — это время никак не работает на словарный запас.
Режим вкраплений (подход Toucan, у которого нет ни личного словаря, ни SRS)
превращает обычное чтение в интервальное повторение: слова из словаря пользователя
появляются в родном тексте на изучаемом языке, прямо в контексте.

## What Changes

- Новый режим работы content script на страницах на языке перевода: расширение
  находит в тексте слова, чьи переводы уже лежат в словаре пользователя, и
  показывает на их месте изучаемое слово с той же подсветкой, что и в разборе.
- Карточка по наведению показывает родное слово (оригинал текста), уровень и
  самооценку «знал / не знал» — ответ двигает запись по той же SRS-лестнице,
  что и тренировка. Чтение родных страниц становится повторением.
- Слова выбираются без модели: сопоставление текста страницы с полем `translate`
  записей словаря. Модель и внешние словари в этом режиме не вызываются.
- Приоритет вкраплений — записи, у которых подошёл срок повторения, затем
  ни разу не тренированные, затем остальные.
- Переключение режимов: текущий разбор сложных слов остаётся поведением по
  умолчанию; режим вкраплений включается явно (настройка чтения + кнопка
  в оверлее). Автоопределение языка страницы решается в design.

## Capabilities

### New Capabilities

- `immersion-mode`: показ слов изучаемого языка внутри страниц на родном языке —
  выбор кандидатов из словаря пользователя, подмена в DOM, карточка с оригиналом,
  самооценка с обновлением SRS, включение и выключение режима.

### Modified Capabilities

_нет: существующих спек в openspec/specs/ пока нет, требования других
возможностей не меняются._

## Impact

- `src/content-script/` — новый механизм показа: в отличие от подсветки, режим
  подменяет текст в текстовых узлах. Инвариант «никакого глобального CSS и никакой
  ломки вёрстки сайта» сохраняется: меняется только содержимое текстовых узлов,
  стили — инлайном, как у текущей подсветки.
- `useDictionary` — чтение записей и обновление SRS-полей из карточки вкрапления;
  компоненты по-прежнему не ходят в storage напрямую.
- `useReaderSettings` — новая настройка режима (в паре «читаю на / перевод на»
  появляется третье измерение: что делать на страницах на языке перевода).
- `ui/options-page/pages/index.vue` (раздел «чтение») — переключатель режима.
- `src/locales/*` — новые строки во всех шести локалях.
- Чистая логика сопоставления «текст страницы → записи словаря» — отдельный
  модуль без браузерных API с тестом рядом (как `llmParse.ts` / `matchesSite.ts`).
- Модель, `analyze.ts` и внешние словари не затрагиваются: режим работает
  полностью офлайн на данных словаря.
